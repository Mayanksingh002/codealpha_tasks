# ✍️ VisionWrite AI — Handwritten Digit Recognition

CNN-based handwritten digit recognition aligned with CodeAlpha Task 3.

### Highlights
- MNIST training
- Random affine augmentation
- Batch normalization
- Dropout
- Label smoothing
- AdamW + cosine LR schedule
- Confidence distribution
- Top-3 prediction display
- Streamlit visual prediction interface

### Run
```bash
pip install -r requirements.txt
python train.py
streamlit run app.py
```
