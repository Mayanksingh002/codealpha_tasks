# 🫀 CardioGuard AI — Disease Risk Prediction

Educational medical-data classification project aligned with CodeAlpha Task 4.

### Highlights
- Heart disease dataset via OpenML
- Logistic Regression, Random Forest and HistGradientBoosting
- Stratified 5-fold cross-validation
- Accuracy, Precision, Recall, F1 and ROC-AUC
- Probability output
- Model comparison dashboard
- Responsible-AI / clinical limitation panel

### Run
```bash
pip install -r requirements.txt
python train.py
streamlit run app.py
```

⚠️ This project is an educational ML demonstration. It is not a diagnostic device and must not be used to make clinical decisions.
